# rebalancer

Bu uzantı, oyun dengesinin birçok yönünü yapılandırmayı sağlar.

## Kullanım

Uzantı girdi olarak yalnızca bir dosya alır. Bu dosya, uzantıyla tanımlanan şemaya uygun bir JSON dosyası olmalıdır. JSON şemalarını destekleyen bir metin düzenleyici, kendi denge dosyalarınızı oluşturmanıza yardımcı olabilir.
