# rebalancer

Это расширение позволяет настраивать множество аспектов игрового баланса.

## Использование

Расширение принимает на вход только файл. Это должен быть JSON-файл, соответствующий схеме, поставляемой с расширением. Текстовый редактор с поддержкой JSON Schema поможет создавать собственные файлы баланса.
