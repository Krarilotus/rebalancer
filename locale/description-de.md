# rebalancer

Mit dieser Erweiterung lassen sich viele Aspekte der Spielbalance anpassen.

## Verwendung

Die Erweiterung nimmt eine Datei als Eingabe entgegen. Diese muss eine JSON-Datei sein, die dem mitgelieferten Schema entspricht. Ein Texteditor mit Unterstützung für JSON-Schemas hilft beim Erstellen eigener Balance-Dateien.
