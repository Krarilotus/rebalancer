# rebalancer

Cette extension permet de régler de nombreux aspects de l’équilibrage du jeu.

## Utilisation

Elle reçoit uniquement un fichier en entrée. Ce fichier doit être au format JSON et respecter le schéma fourni avec l’extension. Un éditeur de texte prenant en charge les schémas JSON peut vous aider à créer vos propres fichiers d’équilibrage.
