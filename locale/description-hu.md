# rebalancer

Ezzel a bővítménnyel a játék egyensúlyának számos eleme beállítható.

## Használat

A bővítmény kizárólag egy fájlt fogad bemenetként. Ennek a bővítményhez adott sémának megfelelő JSON-fájlnak kell lennie. A JSON-sémákat támogató szövegszerkesztő segíthet saját egyensúlybeállítási fájlok készítésében.
