# rebalancer

این افزونه برای تنظیم جنبه‌های گوناگون توازن بازی به کار می‌رود.

## روش استفاده

افزونه فقط یک فایل را به‌عنوان ورودی می‌پذیرد. این فایل باید JSON باشد و از طرح‌وارهٔ تعریف‌شده در افزونه پیروی کند. ویرایشگر متنی که از JSON Schema پشتیبانی کند، می‌تواند در ساخت فایل‌های توازن شخصی کمک کند.
